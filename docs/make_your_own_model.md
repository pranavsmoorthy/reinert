# Reinert Model Creation & Data Management Guide

This guide details how to supply custom data, obtain required SEC mappings, and configure the Reinert application to build and run your own vector graph model. As of the making this file, the data comes from early August, 2026. If More recent data is needed, follow the steps below.

## 1. Where the Data Comes From

Reinert relies on official corporate identifiers to query fundamental SEC EDGAR filings and match them against historical earnings performance. 

* **SEC Ticker & CIK Exchange Data:** You must download the official corporate ticker-to-CIK mapping dataset provided by the U.S. Securities and Exchange Commission.
* **Source URL:** [https://www.sec.gov/file/company-tickers-exchange](https://www.sec.gov/file/company-tickers-exchange)

## 2. Critical File Naming Requirement

To ensure the internal CIK resolution engine can correctly parse and map your company records, **the name of the ticker mapping file cannot change**. 

* The file must be explicitly named and stored as: `ticker.json`

## 3. Making the Model

Start by downloading the whole `data/` folder or extracting `data/data.zip` and working in that. I recommend doing the Python portion of this process in a virtual environment. All the executables and scripts needed for this can be found in the `/data` folder.

Before running the dataset generation script, ensure you have the necessary Python dependencies installed in your environment. You can install them via pip:

```bash
pip install yfinance pandas pandas-ta-classic numpy requests
```

Place your `tickers.json` file in the exact same directory as the Python script.
- If `tickers.json` is missing when you run the script, it will automatically attempt to query and download the top 500 company tickers directly from the SEC endpoint (https://www.sec.gov/files/company_tickers.json) and save them locally to tickers.json.
- If the download fails, it falls back to a default list of major equities.  

Run the python script. This can take a pretty long time, as it took me (on a Macbook M5) anywhere from 10 to 15 hours.

Once the raw dataset CSV has been successfully generated by the Python script:
- Pass the CSV file through your `build_model` executable (part of the VectorForge toolkit).
- The executable compiles the graph and cluster structure into the application's final binary format (`earnings_model.bin`).

The executable must be run from the parent directory of `/data` using:
```bash
./data/build_model
```

## 4. Application Configuration

For Reinert to properly load your custom graph model binaries and ticker mappings, the application must be pointed directly to their file paths via the configuration interface. 

When you launch Reinert, use the **`CONFIGURE EDIT`** command to link the application context to your local resources:

```text
CONFIGURE EDIT <cik_map_path> <graph_model_path> <search_profiles_path>
```
